For Temporary PI positions, replacements, clinician substitutes, Mercator
Fellows, workshops, public relations and other optional modules, use the live
forms page above and download the module form shown there at the time of
submission.

For personnel requests, use the
[current DFG personnel funding rates (form 60.12)](https://www.dfg.de/de/formulare-60-12-246894)
and the values offered in elan; do not freeze a rate table inside this template.
