# Bibliography source

Store optional `.bib` files here. The generic `main.tex` leaves section 3
manual because DFG-specific publication highlighting and the distinction
between applicant and third-party works often require deliberate formatting.

If BibLaTeX is added, keep the visible output within section 3 and verify the
complete titles, DOI or stable URL, applicant-work highlighting and minimum
9-point type requirement.
