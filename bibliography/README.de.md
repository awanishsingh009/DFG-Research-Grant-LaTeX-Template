# Literaturdaten

Optionale `.bib`-Dateien können in diesem Verzeichnis gespeichert werden.
`main-de.tex` lässt Kapitel 3 bewusst manuell, weil die DFG-spezifische
Kennzeichnung eigener Arbeiten und die vollständigen Titel sorgfältig
kontrolliert werden müssen.

Bei Verwendung von BibLaTeX muss die sichtbare Ausgabe innerhalb von Kapitel 3
stehen. Prüfen Sie vollständige Titel, DOI oder stabile URL, die Hervorhebung
eigener Arbeiten und die Mindestschriftgröße von 9 Punkt.
