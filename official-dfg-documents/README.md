# Local official documents / Lokale offizielle Dokumente

This directory is reserved for a local German and English snapshot downloaded
from official DFG sources.

Dieses Verzeichnis ist für eine lokale deutsch- und englischsprachige Kopie
aus offiziellen DFG-Quellen vorgesehen.

Run:

```powershell
powershell -ExecutionPolicy Bypass -File ..\scripts\download_official_sources.ps1
```

Downloaded files are ignored by Git. Recheck the live forms page before every
submission.

Heruntergeladene Dateien werden von Git ignoriert. Prüfen Sie die offizielle
Formularseite vor jeder Einreichung erneut.
